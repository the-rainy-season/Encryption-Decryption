# Encryption & Decryption System

## 📌 Project Description
A Basic Encryption & Decryption System developed in C++ using the Caesar Cipher technique. The application encrypts and decrypts user text by shifting characters using a secret key (shift value), demonstrating fundamental cybersecurity and data protection concepts.

---

## 🚀 Features
- Text Encryption
- Text Decryption
- User-defined Shift Key
- Character Transformation Logic
- Console-based Interface

---

## 🛠 Technologies Used
- C++
- Caesar Cipher Algorithm

---

## 📚 Concepts Applied
- Encryption & Decryption Logic
- String Manipulation
- Functions
- Loops
- Conditional Statements

---

## ▶️ How to Run
1. Open the project in VS Code or any C++ compiler
2. Compile the program
3. Run the executable file
4. Enter text and shift value
